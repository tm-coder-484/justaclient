Latest release as of 4 Nov. Both jars are attached: `+1.21.11` for Minecraft 1.21.11 and `+26.3` for Minecraft 26.3. Put the one for your version in your `mods` folder with Fabric API and Sodium.

## New since 0.12.1

**Mod settings in the Mods panel**
- Nearly every mod showed "No settings". Mods hand their settings screen over through Mod Menu's API, which doesn't exist without Mod Menu installed. The client now puts a small stand-in for it in place at launch, so AppleSkin, BetterF3, Cloth Config mods, LambDynamicLights, Mouse Tweaks and the rest open their settings again. With Mod Menu installed, Mod Menu's own code is used.
- Sodium add-ons such as Sodium Extra open Sodium's settings on their own page.
- Closing a mod's settings goes back to the Mods panel instead of the vanilla title screen.

**Hardening from the M7 to M12 review**
- Saved files are written atomically, and unreadable ones are set aside instead of overwritten (waypoints, maps, lifetime stats), and worlds named in other scripts get their own folders.
- Modrinth installs never leave two copies of a mod on, keep a turned-off old version off, and clean up failed downloads.
- The messaging relay drops connections that have gone silent.
- Smaller fixes: Auto GG ignores player chat, crafting recipe per connection, emoji-safe DM cut, keybind restore, death recap read once, the screenshot gallery frees memory, F1 hides the trinket on 26.3.
- 238 JUnit tests now run on every build.
