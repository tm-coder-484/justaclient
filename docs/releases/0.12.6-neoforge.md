# Justaclient 0.12.6 for NeoForge 1.21.1

Fixes menu/text trails when opening, closing or revisiting menus outside a world.
The title, settings and HUD editor now redraw their backgrounds every frame.
Blur capture waits for buffered background drawing, and offscreen rendering
isolates GUI clipping, write masks and blend/depth/cull state.

The Mods panel reads the loaded-mod graph directly instead of repeatedly
decompressing installed jar-in-jar dependencies. A bad metadata entry, lazy config
factory or image provider is reported without aborting the entire panel.
Bundled mod IDs, dependencies and configuration screens remain accessible.

Validation: 270 unit tests and 57 live framebuffer/menu assertions at GUI scales
2 and 4, using Create 6.0.10, Sable 2.0.6 and Create Aeronautics 1.3.2. The
packaged jar was also exercised in a world with spatial menus and rendering
effects enabled. See `neoforge/PORTING.md` for the commands and test limits.

The user's exact immediate Mods-screen crash has not reproduced in this test
mod set; its exception trace is needed to verify the failing path.
